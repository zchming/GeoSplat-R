## 统计口径

先按原评价规则计算每个种子的三个测试视角算术均值，再对seed42/43/44的场景均值作描述统计：
两组各自均值、样本标准差（ddof=1）、中位数、最小/最大值；同时报告每种子的“统一−零权重”配对差。
PSNR/SSIM正差表示改善，LPIPS负差表示改善。逐图指标恶化完整列出，不能仅凭均值隐藏退化。
不将九张相关测试图当成九个独立场景；不以三个seed给出跨场景显著性或稳定泛化结论。
没有构造显著性p值、按测试集挑选最优seed或重新调整lambda。

三个种子的三个场景均值指标均改善；PSNR配对增益均值+1.3316 dB，中位数+1.4874 dB，
范围+0.4333至+2.0741 dB，样本标准差0.8314 dB。它支持该场景上收益方向重复出现，
但不能称幅度稳定，也没有证明统一深度降低所有指标的种子波动：
PSNR的SD由零权重0.3849变为统一0.4466，LPIPS的SD由0.00164变为0.01107。

九个“seed×测试视角”的PSNR与LPIPS均改善，SSIM八个改善、一个恶化：
seed43/image008的SSIM从0.440251降至0.433098（−0.007153），
尽管其PSNR从16.6229升至16.7416、LPIPS从0.395895降至0.382023。
没有删除该退化项；完整九项对照保存在精简结果JSON。
已实际查看seed43和44的全部三视图对照：黑色缺失在部分图减少，叶片、天花板与背景仍有明显混叠、重影和拉伸。
统一组image016的PSNR在seed43/44仍只有约11.309/11.320 dB，不能把指标改善解释成高质量重建已完成。

训练拟合变化也不一致：seed42统一相对零权重的训练PSNR为−4.6687 dB，
seed43为+4.5919，seed44为−2.2293；三种子训练PSNR均值为零权重48.6348、统一47.8661。
完整训练SSIM/LPIPS与逐图结果均保留，不将训练损失下降或训练退化作为选择种子的依据。

**历史RGB参照仍需单独处理。** 前次单个seed42的RGB基线为15.0197 dB，
本次匹配零权重三个种子的范围仅13.9014–14.6593，均值14.2416，低于该历史单次值0.7781 dB；
即便最高值也低0.3604 dB。统一深度三种子均值相对历史RGB单次值仅+0.5535 dB。
这不是三种子RGB纯路径的配对收益估计，不能与+1.3316混用。
历史RGB与当前RGB+ED零权重路径/源码版本及重复轨迹不同，当前又没有每个seed内部重复，
因此没有拆分种子效应、同seed非确定性、渲染路径和实现维护的影响，不能说原先1.118 dB的落差已经被完全解释。
前一步小场景前向/梯度一致性通过不替代完整训练的基线等价性复核。

## 复现入口与证据

训练/评价入口及显式路径同 [Phase 2 说明](phase2-uniform-depth.md)。将 --seed 分别设为43/44，
每个seed分别设置 --depth-lambda 0 与0.01，保持 --max-steps 30000、--depth-start 1000；所有输出必须新建。
评价使用同一脚本、同一相机/GT/LPIPS权重，--label仅区别方法显示名称。
本机外部根目录为 `~/.local/share/geosplat-r/phase2-seed-stability/`：

- frozen-plan.json、source-evidence：新运行之前的冻结记录与源码副本。
- attempts.json、seed43/44-*-30k 与原始日志：四次运行、完整资源和实际读取清单。
- 对应evaluation目录：六视图指标/对照、Z/alpha、完整PLY、三维图与轨迹视频。
- evaluation-manifest.json：显式指向seed42已有结果与四个新结果，含评价输入来源校验。
- summary：完整汇总JSON和逐种子/逐图比较产物；不把大型生成物纳入Git。

汇总命令如下；manifest通过显式路径列出每个种子的run与evaluation，不依赖本机固定目录：

```bash
"$TRAIN_PY" scripts/summarize_depth_seeds.py \
  --manifest /absolute/evaluation-manifest.json --output /absolute/new/seed-summary
```

manifest格式为 `{"pairs":[{"seed":42,"zero":{"run":"...","evaluation":"..."},"uniform":{"run":"...","evaluation":"..."}}, ...]}`，
必须完整包含42、43、44各一对；输入不一致、哈希不符或run未完成时拒绝生成有效汇总。
源码仓库只保存精简指标、配置、测试与解释；数据、先验、模型、原始日志及完整预测均保留在项目外。

完整测试的资产变量沿用上一步，另提供 GEOSPLAT_SEED_MANIFEST=/absolute/evaluation-manifest.json，
执行 `python -m unittest discover -s tests -v`。缺少实际资产时明确跳过，不作为真实实验通过。
