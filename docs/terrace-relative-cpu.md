# 无锚点相对几何评价器：CPU合成与隔离验收

张总，2026-10-21。**CPU数值核心及合成进程隔离验收通过；本轮不包含真实模型表现。**
按[冻结协议](terrace-relative-diagnostic-plan.md)实现顺序评价器，仅使用程序生成的576×864标签与96×144算术图。
没有读取任何真实GT/RGB/权重/预测缓存，没有加载模型、调用GPU、重建锚点、训练、下载、提交或推送。
[此前72/0/73锚点失败](terrace-cpu-anchors.md)及其停止决定保持不变。

## 实现与边界

[数值核心](../src/geosplat_r/relative_diagnostics.py)支持固定原生节点采样、局部/跨区域配对、
10%深度对比度过滤、两层格等权损失、20次固定节点打乱及并列平均秩Spearman辅项。
原始q为0或极小非负值均保留；精确并列罚0.5，无效端点罚1且留在分母。
四邻居中非有限或负值不得填充；不复用旧q>1e−6的对齐逆Z过滤，不拟合GT仿射变换。

新增[CPU验收入口](../scripts/check_relative_evaluator_cpu.py)，显式接收源码、冻结协议、解释器、合成夹具和全新输出。
当前入口**只接受小尺寸、明确标记的合成.npy夹具**，没有真实ETH3D raw GT或模型调用模式。
supervisor和worker均独立核对合成schema，输入/标签目录严格三文件白名单，标签大小先验校验在内容读取前执行。
真实输入的加载、GPU前向和原生GT统一评价接线仍需后续单独审阅，不能把本轮当作真实端到端验收。
历史CPU隔离启动工具只读复用，旧训练/锚点/评价入口与所有冻结配置原字节保留。

## 隔离与封存顺序

每次集成验收运行两次合成算术函数（非神经网络），预测进程只挂载合成RGB、源码/运行时及自己的新输出；
评价标签、模型、权重、整包与额外视角不可见，网络和GPU设备未暴露。
最新集成中Python、os.open、NumPy和原生OpenCV共**56次禁止读取均被拒绝**。
两次合成集成均通过，总计112次拒绝；第二次在worker schema/目录白名单补强后复核，逐图数值报告完全一致。
改变评价端合成标签后，输入清单、三个算术输出及封存清单逐字节一致。
评价进程独立，只读封存输出及合成标签；所有三个预测的状态、来源、内容摘要及数组形状核对完成后才读标签。

两个预期负测试原样保留：已有输出非零退出且原清单摘要未变；
第三个预测被破坏时非零退出，标签读取尝试列表为空。
这些是受控检查，不是真实数据失败或模型重跑。所有负测试日志、修改后的合成文件及正常输出均保留。

最新集成验收总耗时1.836秒，合成评价体耗时1.278秒；
工作进程最大RSS 60.89MiB，最多4 CPU线程，GPU调用0。
原始夹具、节点/点对缓存、逐格/逐seed统计、执行源码、错误日志及独立复核位于仓库外证据键
`terrace-relative-cpu-20261021T025722Z`。简要结果见[机器可读验收](../results/terrace-relative-cpu.json)。
