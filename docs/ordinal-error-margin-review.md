## 固定描述量：禁止GT支持泄漏

工作图1008×672。只取固定整数中心x=2..1005、y=2..669，共670672像素，使用全部非负有限raw q，零值合法。
将float32精确提升float64后排序，封存每图参考多重集。对任意采样值v，定义
`F(v)=(小于v的参考数 + 0.5×等于v的参考数)/N`。
查询v不一定是参考像素值，必须分别searchsorted left/right；不能先把CDF图插值，更不能按GT有效节点估计CDF。

评分端只读六个既有q文件和两个预测封存清单，不接收GT索引、配对、误差、mask、原图、相机或模型。
可信清单控制器只可对评价文件做不解释内容的字节哈希；评分进程完全不挂载这些文件。六份描述量全部封存后评价器才反序列化配对缓存，以原生节点坐标按旧四邻域规则采样raw q，**先采样q，再查询全局F**。
固定配对风险`S(a,b)=1−|F(q_a)−F(q_b)|`，越大越模糊。
评分与目标共用同一预测q，且样本以GT深度差≥10%为条件；通过只能说明内生歧义对照可用，不能当独立几何证据或错误成因。方向、域、参数在计算前固定，不按结果翻转。
例如纸面参考[0,1,1,3]给F=[0.125,0.5,0.5,0.875]，0/3配对风险0.25，1/1风险1；这不是本轮资产的评分结果。
常量图F=0.5、全部风险1，必须完全无辨别力。
反例：q=[1,2,3]、Z=[1,2,4]时，首末配对排序间隔大、风险仅1/3却完全反序，说明假设可失败而非公式保证。无效端点记最差风险1且旧目标损失仍1，不删除；各对照共享无效最差策略并单报。
参考域有效率低于99%或为空则阻塞描述量，不填洞或改成GT支持mask；当前全图有限/非负只是既有报告，不另作新特征分析。

## 固定目标与风险–覆盖评价

GT对比≥10%、原节点/配对/来源格成员、格≥16支持筛选及旧损失L全部不变；不重新抽样。
L仍为正确0、错/无效1、精确q平局0.5，分层和图/场景聚合保持冻结顺序协议。
候选只是排序**同一批固定L**，不能用翻转/打乱模型q或理想GT预测改变目标，让“风险下降”变成模型变好了。

覆盖率固定25/50/75/100%，主值50%。每个已纳入的格，独立保留最低风险的c×n配对成员质量：
以第ceil(cn)个分数为边界t，S<t权重1、S>t权重0、所有S=t共同取`(cn−count(S<t))/count(S=t)`。
格风险=sum(wL)/sum(w)，精确保证sum(w)=cn。使用分数的精确相等，不加epsilon或用索引顺序打破并列。
然后先格均值、局部/跨区各半、三图场景等权。所有覆盖使用同一批原格，不因分数或错误稀少改变支持集合。
因此coverage1必须逐格/层/图重现旧结果，常数分数在这些无无效端点的样本上各覆盖均等于原风险。
可附报四覆盖风险的离散平均，须明确不是连续AURC，不另用它择优验收。

对照必须完整：

- 常数歧义，无无效时按上述分数并列分数权重精确重现基线。
- 20个score-only打乱：seed42..61，图索引0/1/2，每场景内seed+1000×image_index；对有效节点的F值作一次PCG64置换，复用于两层所有配对。
  **只打乱评分描述量，原q、GT、L和配对不动**，与此前用于验证先验信号的“打乱预测”对照不是一回事。保留各seed和格/图/层结果，不用像素IID p值。
- 风险oracle仅在评价器取S=L，不修改模型预测；在100%覆盖仍是原风险，不能写成0。它与旧q=1/Z的预测oracle不同，不导出给评分端或训练。

## 支持、验收与止损

前置输入关口仅核对清单/来源、字节大小/哈希及预测头部dtype/shape，不生成描述量、不反序列化GT缓存。
精确错误支持须在未来六份描述量全部封存后，由评价器读取缓存再核对，不能提前声称已通过。
输入身份、独立封存、白名单、合成与隔离检查先通过；GT改变不得影响描述量，score置换不得影响L。
六图各至少50个规范唯一错误配对、3个含错误的来源格，且图像R100>0。现有下界只支持有条件规划，尚未核验错误格/节点图。
任一不够记blocked_error_support，保留其他结果，不删图、改对比阈值或增场景以补通过。
另报唯一边、错误关联节点数、最大节点错误占比、格集中度；不声称边/节点独立，也不人为随机拆配对称OOF。

预先固定的开发筛查方向门槛须**全部满足**：

1. 六图各自R50≤0.80×自身R100，且R50≤0.90×自身20次score-only打乱R50均值。
2. 两场景各自三图等权R50≤0.75×自身场景R100，场景平均不能抵消失败图像。
3. 12个图像/层各R50≤R100+1e−12，不能用跨区收益掩盖局部变差；零错误层保留0风险、辨别力仍记unknown_no_error。
4. 常数/oracle与coverage1恒等式、无效惩罚、并列分数权重、所有状态/分母/控制完整且算术复核通过。

这些是评估下一步投入的操作阈值，基于已观察的开发目标提出，但**尚未计算描述量或风险**；不能包装成全程盲预注册。
若方向失败，停止这一个固定间隔假设，不调覆盖/阈值/域、翻号、加特征或重推理。未知支持与已知负结果分别报告。
若通过，也只证明简单歧义对照在已观察场景可用；必须另行评审一个未打开场景，在评分/门槛冻结后独立确认。
不把两个已观察场景互换成“验证集”，不将这次分组称拟合或OOF，也不计算六图当六个独立场景的置信区间。

配对风险不能直接归因给某个像素，更不能直接作为已有米制L1深度损失的权重。
顺序错误与米制残差、可识别性与3DGS收益仍有不同门槛，当前不提出把本评分接入训练。
