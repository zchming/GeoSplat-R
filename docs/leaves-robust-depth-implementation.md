## 目标、梯度与日志

保持原有效像素集合和有效数量分母，使用`r=(1/ED-target)/m`、`rho=c*log(1+(r/c)^2)`。
稳定等价分支避免先平方超大r导致float32溢出；不裁剪、不加epsilon、不按残差大小过滤，也不按影响系数之和归一化。
无效ED和被排除target在求倒数/残差前安全替换，空mask损失与梯度为0；保留原非空像素资格。

Cauchy仅在零基step1000及以后分派；前1000次更新仍走原L1计算、权重0，第1001次更新才启用深度约束。
半强度L1只改已声明的系数，合成输入上的梯度严格为完整L1的一半。默认旧日志节奏不改，诊断模式额外记录第1001次更新。

日志将depth_normalized_l1始终记作原始归一化L1；depth_objective取本次真正参与优化的未加lambda标量，避免把重新汇总的近似值冒充原标量。
另外记录实际/请求目标种类、c、lambda、有效数量、残差分位数、解析影响系数、lambda加权的ED梯度量及视图顺序SHA256。
这些是detach后的诊断，不消耗RNG、不选像素、不反向改变目标或生成置信图。
新校验模块即使在默认L1运行也记录哈希并保存源码；Cauchy数值模块在启用时记录/保存。没有实际运行训练来生成新模型快照。
