# Phase 2：同实现 RGB-only 路径复核

执行日期：2026-10-19。用户授权按上一轮建议补充seed42/43/44的RGB-only各30k，
与保存的RGB+ED零权重及统一深度各三种子比较。不扩场景，不进入可靠性，不提交/推送。

## 为什么需要此复核

[三种子深度对照](phase2-seed-stability.md)中，统一深度相对RGB+ED零权重的场景均值PSNR三个seed均改善，
但该零权重范围13.9014–14.6593 dB，均低于历史单次RGB seed42的15.0197 dB。
历史单次较高不能证明零权重路径被系统性压低，也不能直接归因于CUDA非确定性。
因此冻结当前实现，只增加RGB-only三组，以当前同源码的RGB结果作为更直接的Vanilla参照。
不把历史单次RGB混入新三种子统计，不按效果挑选较弱路径作对照。

## 训练前冻结

配置见 `configs/fern-3view-rgb-path-check.json`，引用上一轮冻结源码哈希。
相机、图像、训练三角化488点、归一化、seed、采样算法、优化器、SH/增密策略、30k预算均保持不变。
保持504×378、batch=1、float32；不重建数据，不下载新文件，不重新生成先验。
三次新训练依次执行，全部结束后再评价，防止新测试结果影响后续运行设置。

| 路径 | 训练渲染 | 先验缓存与深度诊断 | 深度反向项 |
|---|---|---|---|
| 新增RGB-only | RGB | 无 | 无 |
| 已有RGB+ED零权重 | RGB+ED | 有 | 无 |
| 已有统一深度 | RGB+ED | 有 | lambda=0.01，零基step1000起 |

调用同一个train_baseline.py：新增RGB-only不传 --depth-priors，显式 --depth-lambda 0，
保持 --depth-start 1000（该路径无深度项，不改变RGB训练调度）。不为本实验修改训练/深度/评价源码。
同一个seed的三条路径必须具有相同初始参数哈希，不能从已有收敛检查点继续训练。

**因果边界：** 两条零深度路径同时存在ED通道、先验缓存和未反向深度诊断的差异。
本步是整条路径的描述性复核，不能孤立归因到某个CUDA内核；每个seed/路径只有一次，
不能分离同seed重复方差与路径效应，也不以n=3宣称正式等价或显著性。
前一步小场景前向/梯度一致性检查只排除其条件下的明显差错，不证明长程增密等价。

训练仅接收prepared/train并审计实际读取；RGB-only不读深度先验、测试RGB或测试相机。
评价均调用原脚本的RGB+ED渲染，以保存同口径RGB指标/深度可视化；测试GT、clamp、SSIM/LPIPS及权重一致。
不是给RGB-only单独更换评价通道或调整测试后处理。

**路径疑点得到更直接的观测证据，但没有确定原因。** RGB+ED零权重的三个seed场景均值在三个指标上均弱于RGB-only：
PSNR差为−0.6403/−0.0981/−0.7579 dB，均值−0.4988、样本SD0.3520；
SSIM均值差−0.025097，LPIPS均值差+0.016179。
因此不能继续将两条路径当作已经验证的质量等价基线，也不能把历史落差全解释成不同seed。
这仍不是“ED内核有bug”的证明：先验缓存/诊断、执行轨迹和同seed非确定性没有被分别消融，
每条路径每个seed只有一次，本步没有提供正式等价检验或因果归因。

**使用预先选定的RGB-only主参照，深度信号仍存在。** 统一相对RGB-only的测试PSNR配对差为
+1.4338/+0.3352/+0.7295 dB，均值+0.8328、样本SD0.5565，范围+0.3352至+1.4338。
测试SSIM均值差+0.015949，LPIPS均值差−0.026062；三个seed的三个场景均值指标均改善。
此前相对RGB+ED零权重的+1.3316 dB仍是正确的该控制组差值，但不应当作对较强RGB-only的收益。
两种收益相差0.4988来自参照组数值差，这是算术分解，不是对差异机制的解释。

逐图不能报全胜：统一相对RGB-only的九个PSNR有8个改善、1个恶化，SSIM同样8/9改善，LPIPS为9/9改善。
两项退化是seed43/image016 PSNR从11.9426降至11.3087（−0.633831 dB），
以及seed43/image008 SSIM从0.434620降至0.433098（−0.001523）。
完整三个对比的27项逐图差与所有指标退化均保留在结果JSON，没有按均值过滤。
已实际查看三个seed的全部三视图四列对照：各路径仍存在细叶混叠、反射/背景拉伸与外推区域重影；
指标改善不等于高质量重建完成，没有独立密集真值支持几何准确率提高的结论。

当前RGB-only seed42为14.5417 dB，比不同源码版本的历史RGB单次15.0197低0.4780。
该历史参考单独保留，没有混为第四个样本，也不能作为严格同源码重复方差。

## 复现与证据

在 [当前环境和数据](reproduce-fern.md)基础上，分别将 --seed 设为42/43/44，输出使用三个新目录：

```bash
"$TRAIN_PY" scripts/train_baseline.py \
  --data "$FERN_WORK/undistorted-prepared/train" --source "$GSPLAT_SOURCE" \
  --output /absolute/new/seed42-rgb-30k --seed 42 --max-steps 30000 \
  --depth-lambda 0 --depth-start 1000
```

三个模型各自用原evaluate_baseline.py评价，传相同train/test目录和LPIPS权重、独立新输出；
--label只改变显示名称。完整数据路径清单位于项目外evaluation-manifest.json，随后汇总：

```bash
"$TRAIN_PY" scripts/summarize_rgb_paths.py \
  --manifest /absolute/evaluation-manifest.json --output /absolute/new/path-summary
```

manifest包含depth_manifest（上一步六个run的显式清单）、rgb_runs（三个含seed/run/evaluation的记录）。
入口核对九个run的源码、配置、初始化、读取清单、检查点与指标，并逐图核对测试GT哈希。
任一种子缺失、预算不足、均值不符或使用了错误视图都会拒绝汇总；输出目录已存在时拒绝覆盖。
统计先算每个seed的场景均值，再对三个seed求均值、样本SD、范围、中位数与配对差。
PSNR/SSIM正差为改善，LPIPS负差为改善；完整列出逐图退化，不把九张相关测试图当独立场景。

完整证据保存在项目外 `~/.local/share/geosplat-r/phase2-rgb-path-check/`：
frozen-plan、source-evidence、analysis-source、attempts、三个新run及原始日志、三个独立评价、
evaluation-manifest、summary和测试/资源记录。六个深度对照和历史RGB输入/模型/报告全部保留。
仓库仅纳入解释、冻结配置、精简指标与统计/来源检查，完整预测与模型不入Git。

完整测试变量沿用上一步，并补充GEOSPLAT_RGB_PATH_MANIFEST指向本步evaluation-manifest.json，
运行 `python -m unittest discover -s tests -v`；缺少真实资产时明确跳过。

## 验收及下一步

**本授权小步工程验收通过；不接受两条零深度路径已等价的结论。**
不能将RGB+ED零权重较弱的对照当作唯一Vanilla参照；后续以训练前已选定的RGB-only为主基线，
同时保留RGB+ED零权重来估计相同渲染/诊断路径下的深度项增量，不按seed或指标挑选较弱基线。
这是采用双对照控制不确定性，不是隐去路径差异，也不是已定位或修复了内核问题。

统一深度相对两组对照的三个seed场景均值方向均正，足以支持继续Phase 2跨开发场景验证；
