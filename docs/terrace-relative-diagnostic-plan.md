# 无锚点相对几何诊断：可行性与冻结协议

张总，2026-10-21。**有条件值得做一次限额的相对结构诊断；建议先实施CPU评价器及合成/隔离验收。**
本轮仅方案评审，没有新实现、特征/锚点准备、模型/权重加载、推理、真实GT分析、训练、数据/权重下载、提交或推送。
[原锚点试点](terrace-cpu-anchors.md)的72/0/73结果及停止决定保持不变，不能把新协议算作原试点通过。
[完整参数与逐资产摘要](../configs/terrace-relative-diagnostic-plan.json)独立冻结，旧公制协议原样保留。

## 能回答什么，为什么仍值得限额验证

原三图锚点缺失阻止了不依赖GT的公制对齐，但单目相对预测仍可与传感器的近远关系直接比较。
本轮唯一问题是：**Small原始相对逆深度是否在同一图内保留了独立激光观测的近远顺序？**
不需要生成锚点、拟合尺度/偏移、估计相机或让GT进入模型输入。
如果连这一弱条件都不成立，不值得在该固定试点上继续叠加几何权重；通过也只是相对结构信号。

严格递增的非线性失真可以保持全部近远顺序，同时产生错误的公制深度；这会作为强制合成反例。
因此本诊断不能认证公制Z、仿射可校准性、三维初始化、跨视图一致性或任何可靠性权重收益。
点对错误也不能直接归因到某一个端点，不能把点对图涂成逐像素真实深度误差。
D1/D2/H1与Cauchy负结果不恢复，本步不提出新评分、不追加训练。

## 固定预测与映射

仍用原来的DSC_0259、0271、0285及其选中相机/尺寸导出；其他视角、官方全点云、锚点/特征缓存不可见。
RGB原生6048×4032，用INTER_AREA精确缩小6倍到1008×672，不去畸变或改变画幅。
只使用已存在的Depth Anything V2 Small权重及固定源码，15文件摘要、权重SHA256沿用前次评审。
本轮读取[官方论文相对深度段落](https://arxiv.org/html/2406.09414v2#S7.SS2)，确认基础模型输出为仿射不变逆深度；
论文不为本方案阈值、terrace表现或研究创新提供背书。
未来若获准，仍为float32、batch1、seed42、input_size518、预期NCHW=1×3×518×784，每图一次。
三个raw输出及输入/源码摘要全部封存后，独立CPU评价器才能读取三张GT；不逐图反馈后再改预测。

GT保持原生小端float32相机轴Z。正有限值有效，正无穷未知，不填洞、不缩放或插值GT。
原生像素(i,j)映到工作数组((i+0.5)/6−0.5,(j+0.5)/6−0.5)，固定域为
2≤x≤1005、2≤y≤669；域外、GT缺失、预测无效分别报告。
在原生有效位置双线性采样**raw相对逆深度q**，不对齐、不取倒数当Z、不改符号。
四个参与工作像素均须有限且非负，包括零权重邻居；否则样本预测无效。

**q=0是合法预测值，可形成并列。**固定源码forward确实使用ReLU，不能沿用
sensor_geometry.sample_inverse_z的q>1e−6过滤：该函数为另一条已对齐的逆Z路线设计。
新评价器需要独立的raw采样合同；全零预测必须留下，并得到常数对照的0.5顺序损失。

## 样本与点对：冻结算法，不按预测挑选

使用NumPy1.26.4/PCG64，所有列表按原生行优先索引稳定排序。未来只在全部预测封存后生成评价样本。
图像索引为固定字典序的0/1/2，网格为12×9，cell=row×12+column；网格边界为原生整数半开区间。
每格在固定域内列出有效GT位置，以seed=42+108×image_index+cell对位置列表随机排列，最多取64点，
然后按原生索引排序。少于64点全部保留；每图最多6912点，不枚举全分辨率所有点对。
模型值和有效预测mask不能改变这些位置或配对。

| 分层 | 固定候选构造 |
|---|---|
| 局部 | 每格所选点的所有无序点对；超过256则按固定PCG64排列取前256，不足则全部 |
| 跨区域 | 每个有样本的源格作256次固定随机抽取：源点、目标格、目标点；目标格须非空且网格Chebyshev距离≥3 |

局部seed为100000+108×image_index+cell；跨区域为200000+108×image_index+cell。
跨区域点对统一端点顺序、仅在同一源格内去重；跨源格重复保留归属以维持源格等权，另报唯一点对与重复量。
不把重复点、共享端点或邻近格视作独立统计样本。

候选生成后，仅保留`max(Za,Zb)/min(Za,Zb)≥1.10`的GT对，**不补抽**。
其余作为低对比度排除，完整报告分母。10%是事前固定的投入过滤规则，不冒充激光误差界，
也不声称能认证近等深表面的排序。深度相同或同一平面的有效对不足时，按支持不足处理，不降门槛。

## 主损失、聚合与对照

方向固定为q越大越近。GT对已有足够深度差，不存在有效GT并列：

| 情况 | 顺序损失 |
|---|---:|
| 预测近远方向正确 | 0 |
| 两端q精确相同 | 0.5 |
| 预测方向相反 | 1 |
| 任一端预测无效 | 1，保留在分母 |

实现使用符号比较，避免差值乘法溢出；不引入依赖q尺度的并列epsilon。
每格至少16个合格对才进入该分层主均值；先各格均值，再该分层格等权。
每图主损失=0.5×局部格均值+0.5×跨区域源格均值，场景主损失为三图等权均值。
低对比/不足格数量及其无效预测照常展示，不按模型好坏选择格，不混池百万像素提高表观证据强度。

| 对照 | 固定解释 |
|---|---|
| 常数q=1 | 所有合格对损失0.5；全零模型同样应为0.5 |
| 模型值随机打乱 | 20个seed42…61，各图用seed+1000×image_index；固定无效位置，仅置换有限非负节点q值 |
| 评价器内理想q=1/Z_GT | 所有合格对损失0，用于校验上限；禁止输出给预测器或训练器 |

每次打乱只生成一套节点值，供所有共享节点的局部/跨区域对复用，不能逐对独立造随机标签。
保留每个seed及均值/范围；不报告把像素、点对或三张相关图当独立重复的p值/置信区间。
抽样有效节点的Spearman（并列平均秩）仅为辅项；恒定/不足时记unknown，不能替代主门槛。
不沿用旧公制AbsRel收益、不绘制缺乏候选评分的可靠性风险曲线，不挑符号或随机seed。

## 支持关口与停止标准

每图须至少1024个抽样GT节点；每个分层至少12个纳入格、合计至少256个合格对。
不足时结论为blocked_relative_support，保留可算的逐图统计，但整体不能通过，不能删图继续。
这项真实支持尚未测量；原数据摄取的覆盖不能保证10%对比度配对充足。

后续真实评价只有同时满足以下条件，才认为值得进一步评审相对误差靶标：

- 每图全部抽样节点的无效预测比例≤1%，各分层主样本中含无效端点的点对比例≤2%。
- 三图的局部、跨区域两层损失分别都须≤0.40，因此每图主损失也≤0.40；三图等权均值≤0.35。
- 每图比该图20次打乱的平均损失至少低0.05。

这些是新问题的事前操作门槛，不是统计功效或几何精度保证。局部/跨区域分层和每格结果均完整报告。
不通过则停止该固定相对诊断，不调方向、对比度、采样数量或追加场景/推理。
通过也只支持另审独立误差靶标及可证伪的评分假设；没有公制准确度、错误定位或公平训练收益证据时，
不放行可靠性加权，不恢复原锚点对齐路线，不把普通Small模型表现包装为算法创新。
