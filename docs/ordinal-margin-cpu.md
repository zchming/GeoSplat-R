## 实现与隔离

`run_ordinal_margin_cpu.py` 提供 validate、describe、evaluate 三个显式阶段，要求指定源码、方案、资产位置清单、解释器及新输出位置，拒绝覆盖或与输入重叠。CPU 沙箱隔离网络、GPU与非白名单文件。describe 仅挂载八个预测及封存文件，配置不包含评价标签或完整方案中的已知错误统计。六幅描述量全部封存、哈希与来源一致后，evaluate 才挂载评价资产；评价工作进程再次验证全部封存文件，然后解释缓存。

实现固定 CDF 中秩、先插值原始预测再查询 CDF、无效样本保留并赋最大风险、边界并列分数分数权重、原有单元宏平均、20 次仅分数置换、常数与风险 oracle 对照。所有全覆盖损失必须以 1e-12 容差复现既有损失。错误图支持不足时保留支持统计并阻断风险曲线，不调整假设。
