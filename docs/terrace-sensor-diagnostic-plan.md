# terrace 独立传感器真值诊断：冻结方案评审

张总，2026-10-21。**方案有条件通过，建议下一步仅实施最小CPU适配、合成/隔离检查及一次三图锚点支持准备。**
本轮只审阅与冻结协议，没有实现入口、提取特征、匹配、三角化、推理、读取新误差、训练、下载、提交或推送。
[数据摄取验收](terrace-native-intake.md)已经通过；其覆盖与可视化已看过，因此terrace始终是开发诊断场景。
本方案冻结在新预测与真实误差可见之前，不能冒充标签从未可见的预注册盲测。
完整参数、资产摘要、停止标签及授权边界见[机器可读协议](../configs/terrace-sensor-diagnostic-plan.json)。

## 优先检验的问题

先回答：**只用固定三张RGB生成的锚点，能否把单目先验对齐到优于常数深度的真实几何参考？**
这比在未证实的参考上继续设计评分更值得投入。D1/D2/H1及固定Cauchy负结果保持原结论，
本方案不重跑它们，不提出新的几何可靠性评分，也不以梯度对照充当创新方法。
原始锚点传感器误差另作归因诊断；锚点自身的重投影残差不能当独立真值。

## 输入和最小相机适配

固定训练输入为DSC_0259、0271、0285，保留原生6048×4032及其三项相机。
预留DSC_0262、0267、0275、0279及其他视角不提取、不解码、不参与锚点/对齐。
源RGB、相机导出、评价GT的逐文件SHA256沿用摄取证据；新协议记录7项资产，但预测端只能收到4项。

原始畸变RGB使用INTER_AREA精确缩小6倍到**1008×672**，不裁剪、不去畸变、不下载新数据。
这是独立诊断分辨率，不替换历史LLFF的504×378协议，也不与旧3DGS指标直接比较。
Depth Anything V2并非为该畸变场景提供精度保证；这个限制由真实评价暴露，不能靠转换GT掩盖。

| 数据/接口 | 固定坐标转换 |
|---|---|
| OpenCV特征工作坐标(x,y) | 转COLMAP角点坐标为(x+0.5,y+0.5) |
| 原生GT数组像素(i,j)中心 | 工作数组坐标为((i+0.5)/6−0.5,(j+0.5)/6−0.5) |
| 原始相机到工作相机 | fx/fy/cx/cy除6，八项畸变参数不变 |
| 特征工作坐标到原生角点 | (6(x+0.5),6(y+0.5)) |
| 世界/相机与深度 | 原始公制，世界到相机Hamilton四元数归一化；Z是轴深度，不是单位射线长度 |

ray lifting必须使用完整THIN_PRISM_FISHEYE；独立CPU相机助手使用pycolmap 4.2.1。
不复用只支持针孔的旧入口，不加载官方全场景Reconstruction或points3D，不优化相机或通过GT/ICP对齐。
OpenCV与现代pycolmap位于两个既有环境，后续用显式选中相机/观测文件作进程交换，避免替换旧解析器。

## 锚点与先验：全部不读取GT

固定OpenCV 4.11 SIFT CPU：最多8192特征，3层/组，contrast=0.04，edge=10，sigma=1.6，
关闭precise upscale，线程4，seed42。三对图穷举BF-L2，双向k=2，两个方向均严格ratio<0.8，互为最优。
不引入学习匹配、姿态RANSAC或其他初始化研究路线。

按匹配边合并轨迹；同一轨迹出现同图多个特征则整条拒绝。保留2/3视角轨迹，完整模型反投影后用
float64齐次DLT/SVD和已知姿态三角化，无额外优化；要求有限、所有观测Z>0、最大射线夹角≥1.5°、
逐观测重投影误差≤2工作像素、测量位置离边界≥2像素。
导出**真实SIFT测量坐标**，不沿用旧导出器的拟合重投影坐标。
同图同最近整数像素仅留最近正Z点，精确平局按稳定轨迹签名；保留所有拒绝数量和原因。
每图至少60个锚点、12×9网格至少12格有锚点；不足即blocked_anchor_support，不换图或放宽过滤。
这些是投入门槛，不是锚点精度保证。

未来推理仅用现有Small权重：99,218,434 bytes，SHA256
`715fade13be8f229f8a70cc02066f656f2423a59effd0579197bbf57860e1378`；
模型源码版本`a561b849ebae10a6f5ef49e26c83cbbcd36c71bf`及15文件摘要不变，本轮已核实未漂移。
每图1次，batch1、float32、input_size518、无xformers、seed42。
上游Resize静态尺寸规则对应NCHW **1×3×518×784**；infer_image返回1008×672，保留其align_corners=True上采样。
执行前必须实测断言形状，不因OOM改尺寸/精度重试。

每图在真实锚点测量位置双线性采样raw相对逆深度，float64等权OLS拟合
`q_pred=a*q_raw+b`到`q_anchor=1/Z_anchor`。不借GT筛锚点、定符号或拟合尺度/偏移。
要求样本标准差≥1e−6、a>0，固定内部区域q>1e−6的比例≥50%；失败记录failed_alignment并停止，
不改鲁棒拟合、不翻转符号、不夹到正数兜底。

## 固定评价、对照和未知

预测端完成所有三图并封存锚点、raw/aligned预测、常数基线及读取清单的摘要后，独立CPU评价器才读取GT。
GT保持原生小端float32；仅正有限值提供真值，不插值或填洞。
固定评价域为映射后2≤x≤1005、2≤y≤669的原生像素，边界剔除数量独立报告；
域不依赖预测是否有效。每图该域仍须≥5000有效GT点，且12×9网格≥30格各≥20点；否则标签支持不足而非方法失败。

在映射位置双线性采样**对齐后的逆Z**再取倒数，四个参与像素均须正有限；否则预测无效。
主误差为`min(|Z_pred−Z_GT|/Z_GT,1)`，无效预测罚1，不能删掉无效点改善均值。
先逐图均值，再三图等权；辅报有效预测上的未截断AbsRel、按训练锚点逆Z中位数归一化的逆Z误差，
必须同时给出无效比例和分母。GT缺失、固定域外、预测无效三类分开。

| 对照 | 用途与限制 |
|---|---|
| 每图常数q=median(1/Z_anchor) | 同锚点、同评价域的主基线，不使用GT |
| 对齐q的中心差分梯度幅值/训练锚点逆Z中位数 | 固定低分优先，仅为简单空间排序对照；不能称几何可靠性模块 |
| PCG64随机排序，seeds42…61 | 评价器固定GT域内随机排列，保留每个seed及均值/范围 |
| 按真实截断误差排序 | 只供评价器绘制理想参考，禁止传回预测端 |

风险曲线固定覆盖25/50/75/100%，每档保留ceil(覆盖×该图固定域有效GT数)；
平局按原生行优先索引，无效梯度分数排末，所有曲线包含所选无效点的罚1及无效计数。
梯度先在工作栅格求中心差分再采样；不按结果换排序方向、调覆盖点或挑随机seed。
评价器固定NumPy1.26.4；梯度邻域无效导致分数不可用时排末，区别于深度预测本身无效。
空间块统计描述异质性，不把百万像素或相邻视角视作独立重复样本，不报告虚假显著性。

锚点自身的传感器误差只在其映回原生角点后floor得到的**单个确切像素**有GT时计算，
不搜索附近有利标签。每图至少30个有支持的锚点才解释该项归因统计；不足记unknown，
不阻止已经具备足够域支持的主预测评价，也不按这项结果重选锚点。

## 隔离、资源与放行顺序

旧audit_training_reads限制data.parent范围，且不拦截所有原生库读取；它不能证明当前兄弟评价目录的隔离。
现机有bubblewrap 0.9.0，但本轮只核实版本，尚未验证用户命名空间或GPU设备挂载能力。
后续预测进程须按白名单挂载选中RGB/相机、模型源码/权重、必需运行时与新输出；
禁止宽泛挂载数据/历史证据父目录，使GT、整包、完整标定及其他视角在进程内不可见。
CPU助手同样只读选中观测，评价进程与预测进程分开，评价结果不回流。

实现验收必须用合成哨兵标签测试Python/os.open/NumPy/OpenCV均无法越界读取，
并验证标签变化不改变预测端输入清单及合成输出、旧输出拒绝覆盖。
命名空间或设备隔离不可用时记blocked_isolation并停查，不能自动改成挂载整个证据目录。
这项检查未通过前，即使数值相机测试通过，也不能放行真实锚点准备或模型调用。

CPU最多4线程、RSS2GiB、锚点准备600秒、新输出2GiB；按单图/单随机seed流式评价。
未来GPU限本机12GiB，实测allocated/reserved/整卡峰值和耗时，不用填满显存作为目标。
无新下载、云资源或训练；GPU前向预检仍需后续单独放行，异常/OOM停止，不自动重跑。

1. **本轮完成：**方案与静态一致性评审，不执行数据/模型算法。
2. **建议下一步：**另行批准最小CPU适配、合成与隔离检查；通过后一次固定三图锚点支持准备，不加载权重、不推理。
3. **之后再判断：**CPU支持与隔离通过才评审GPU前向预检及三次Small推理；三图齐备后统一读取GT评价。
4. 任一关口失败/未知均保留证据并停止，不自动追加场景、运行或训练。

## 判定与止损

工程通过与研究收益分开：负结果也可以是完成且可信的诊断。
真实评价中每图无效预测率须≤5%；主误差须**三图各自严格优于常数基线，且场景等权均值相对降低≥5%**，
才通过本次metric-viability投入门槛。任一图常数基线误差为0则为inconclusive_floor，不除零或宣称收益。
门槛是事前固定的工程投资判断，不是理论精度界或统计功效保证。
不通过则停止该固定先验/对齐试点，不按GT调过滤、调系数或追加运行。

即便通过，也只支持另审外场景确认及可证伪的几何评分假设，不支持直接进入可靠性加权或3DGS训练。
累计贡献仍是独立传感器参考及其可证伪评价路线；本轮没有新增精度、排序或方法创新结果。
