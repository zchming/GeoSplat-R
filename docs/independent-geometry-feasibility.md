张总，2026-10-20。**有条件值得继续一次限额的传感器真值数据摄取与验收；不值得现在继续叠加评分或启动可靠性训练。**

## 判断依据与候选筛选

D1、D2和[原始轨迹H1](leaves-raw-track-diagnostic.md)均未建立稳定的错误辨别依据，
固定Cauchy对照也没有通过收益门槛。不能用另一套SfM残差继续替代几何真值。
传感器来源的几何观测可以检验此前无法判断的“参考本身是否在错”，但数据存在
不等于新方法值得训练，也不证明任何旧评分应当复活。

| 数据候选 | 真值及相机来源 | 本项目的取舍 |
|---|---|---|
| ETH3D high-res multi-view公开training数据 | 激光扫描投影深度，带已对齐的相机；有缺失与可见性筛选 | **首选terrace**；独立于本项目SfM点和单目先验，但不是每像素稠密真值或独立三图标定 |
| DTU MVS 2014 | 结构光扫描参考、机器人采集及标定投影矩阵 | 真实传感器备选；官方最小SampleSet仍大，实际单位/标定ReadMe和成员尚未摄取 |
| TUM RGB-D | Kinect深度与RGB配准、光学动捕轨迹 | 可作格式/单位备用验证；噪声、时间关联和预配准增加混杂，不优先替代静态高精度表面参考 |
| BlendedMVS | 重建纹理网格渲染的深度与MVSNet相机 | 可用于渲染一致性检查，**不作为独立物理传感器真值的首选**；全套分卷过大 |

来源：[ETH3D数据页](https://eth3d.ethz.ch/datasets)、[官方生成管线](https://github.com/ETH3D/dataset-pipeline)、
[DTU说明](https://roboimagedata.compute.dtu.dk/?page_id=36)、[TUM格式](https://cvg.cit.tum.de/data/datasets/rgbd-dataset/file_formats)、

## ETH3D相机、坐标和参考深度合同

官方[格式说明](https://eth3d.ethz.ch/documentation)规定原图使用THIN_PRISM_FISHEYE，去畸变版为PINHOLE，
相机文件按camera_id关联；同一物理相机可有不同标定块，不能把image_id当数组下标或只取首个K。ID=0也是合法标识，
不能直接套用旧leaves入口的正ID/PINHOLE限制；本步不改旧入口。
images.txt采用COLMAP的世界到相机姿态：Hamilton四元数qw,qx,qy,qz及平移t，
`X_camera = R*X_world+t`；相机中心为`-R.T*t`，c2w为该变换的逆。
这与TUM的qx,qy,qz,qw、camera-to-world约定不同，不复用解析分支。

官方生成器在[固定源码版本](https://github.com/ETH3D/dataset-pipeline/blob/e09275b39b30c9c59abf535b849fcc539dc03efd/src/exe/ground_truth_creator.cc)
中使用image_point.z()写入GT，未观测处初始化为infinity，观测处取最近Z。
GT是图像大小的原始4字节float缓冲区，可沿用.JPG文件名，不能用JPEG解码器读取。
它来自可见性及mask过滤后的激光点，**没有保证所有像素有效**；不是插值稠密标签。
实际文件的字节序、是否额外压缩及`4*W*H`尺寸仍须摄取核验，不能仅凭扩展名决定。
单位按ETH3D公制坐标处理，摄取时与相机平移、官方说明及合理量级共同核对，不拟合GT尺度兜底。

标定文件以图像左上角为原点，数组像素(i,j)中心对应角点约定坐标(i+0.5,j+0.5)。
[官方COLMAP导出实现](https://github.com/ETH3D/dataset-pipeline/blob/e09275b39b30c9c59abf535b849fcc539dc03efd/src/io/colmap_model.cc)
显式对相机参数与观测加0.5。适配到整数像素中心坐标时可等价地将cx/cy减0.5，
两种写法只能选一种贯穿全程，必须用合成边界点与独立相机API交叉核对。
THIN_PRISM_FISHEYE不能当作SIMPLE_RADIAL或普通Brown五参数模型。

首轮摄取保持**原始畸变RGB、原始标定、同名原始深度**，不做自动去畸变或缩放。
后续需要接入针孔管线时，须独立核对同名图、相机中心/方向及像素映射，不能直接对齐两个栅格。
可在原始GT有效像素上以真实相机模型取射线、映射到预测坐标采样预测，而保持参考Z不插值；
若还旋转了相机坐标轴，须同步变换三维点及Z，不能只remap一个标量深度。
不填洞，不跨深度边界做普通双线性GT插值，不把缺失当作远处背景或正确深度。

若未来沿用训练相机归一化`X'=(X-c)*s`，须同时使用`Z'=s*Z`、`q'=1/(s*Z)`，
其中c/s仅由选中训练相机定义。不得用测试GT/ICP寻找有利的尺度、刚体或裁剪。
本次最小包不含原始激光扫描或scan_eval点云；不声称能据此完成官方表面重建基准。

“独立”仅指参考测量来源独立于本项目SfM点/深度先验。ETH3D相机经激光/图像对齐，
GT可见性也可能利用完整数据集；这是给定已标定相机的条件验证，不是严格仅三图恢复相机。
预训练深度模型是否见过这些公开场景也不能凭本次核查排除；不能据此宣称模型预训练层面的盲测泛化。

## 训练、诊断评价与最终测试的隔离

1. terrace固定为**工程与开发诊断场景**，不宣称最终独立测试。数据页列23张图；
   未来先只解析标定/成员列表，将完整相对图名按字典序排序，以0基rank 0/11/22固定三训练图。
   若不是23张、存在重复映射或不匹配则停查，不按GT质量/重建效果改选。
   本轮未获知真实图名，不能宣称3张输入已冻结完成。
2. 同场景rank 3/7/15/19预留为未来新视角评价，其余不用于训练；三图摄取验收期间不解码这些RGB/GT。
   给定相机全表可作来源元数据，实际训练输入只导出选中的3项相机和3张RGB；不导入全量points3D/track。
3. **三训练图的传感器GT也只交给独立诊断评价器**。评分/先验对齐/初始化/优化器不得访问GT、GT有效mask或
   原激光点云。先验尺度/偏移仍只能由训练RGB重建的锚点拟合；禁止按每张GT最优仿射再报主误差。
   如需要oracle对齐，只能作为清楚标记的另项上限诊断，不能作训练输入或主结果。
4. 物理目录与进程分离：预测端只读train的RGB/相机/训练派生量；评价端另读labels。
   整包中混放的其他视角保留在原压缩包，先检查成员再按清单受控提取，拒绝路径穿越、软链接逃逸和覆盖。
5. courtyard、delivery_area仅是未来确认/开发候选，本次没有读取其GT。若将来参与方法选择，就不能再称最终盲测。
   最终另需预先锁定未用于设计的场景及评价协议；官方未公开GT的test分区不能假装可本地直接评价。

未知GT区域只计覆盖/未知，不赋真值；官方GT支持mask不传播给训练器或权重函数。
像素和相邻视角不是独立样本；逐图、逐块、逐场景汇总，不能混池数百万像素制造显著性。

## 是否值得继续：分层验收与止损

| 关口 | 本次状态或后续要求 | 通过后允许的最小推进 |
|---|---|---|
| 文件可达与成本 | 推荐两包均最终200，精确长度已核实；成员/内容/解压字节未验 | **仅建议另行批准两包下载和一次CPU摄取验收** |
| 内容与坐标 | 逐成员SHA256、图名/相机ID、原始畸变模型、四元数方向、半像素、Z/单位、字节数全部通过 | 才能认为参考数据可用；目前为待验，不能直接称数据准备完成 |
| 有效支持 | 拟议每图>=5000个正有限GT点、原生有效比例>=1%，12×9网格至少30格各>=20点；三图均满足 | 足以投入一次独立真值诊断方案评审；这些是投入门槛而非功效/精度保证 |
| 参考的边界 | 报告缺失、遮挡/反光区域、原生支持和变换后有效率，保留失败；不靠填洞达标 | 若不足即停止该最小试点，不擅自扩大下载或替换场景 |
| 新方法证据 | 另行冻结可证伪假设，再生成预测并独立评价；比较实际先验错误与候选排序，包含简单/打乱对照 | 不根据本轮数据可达就恢复H1/D1/D2、设计新权重或训练 |
| 进入可靠性研究 | 传感器标签证据与跨场景确认支持后，另审最小可解释模块及公平训练矩阵 | 当前不放行；三个以上开发场景的真实对照仍未完成 |

后续真值诊断建议同时报告原生有效覆盖、预测无效比例、AbsRel/逆Z残差，以及固定覆盖率
25/50/75/100%的风险曲线，避免只留下“容易预测”的像素。主统计先图均值再场景等权，
已知错误/无效预测与GT未知分开。具体评分、主量、容差和停止标准须在新标签结果可见前另行冻结，
本表不是可直接执行的模型评价或训练矩阵。

首轮未来摄取建议只做下载完整性、标定/栅格/支持检查，CPU最多4线程、RSS预算2GiB，按单图流式处理。
建议解压/工作空间预算上限10GiB；真实展开字节尚未知，须下载后先列7z成员，超预算即停，不盲目全量解压。
不需新模型或权重，不需编译完整ETH3D生成管线，不重新渲染扫描GT。上述预算均为规划，不是实测。
若数据关口通过，下一轮才讨论是否值得批准单目先验推理及一次冻结真值诊断；不包含Gaussian训练。

本轮累计贡献是确认独立测量来源、成本清单和坐标/隔离风险，补齐继续或止损的判断依据。
