## 为什么只检查这一个信号

原总指令的候选路线是先验证多视图几何一致性，再考虑可靠性权重。
[D1结果](leaves-train-error-coverage-d1.md)未支持锚点距离；距离只是空间支持，不直接比较不同视图的深度预测。
D2固定检查“不同训练视图的先验是否在投影位置发生深度冲突”，不混合颜色、距离或多个评分，不重试不同聚合方式。
这是在已知D1结果后提出的新开发假设，不是预注册验证或未知测试结果；也不能靠多加诊断保证项目成功。
若此信号证据不足或反向，本范围内停止该评分路线，不无限叠加公式。

| 比较项 | 已完成D1 | 拟议D2 |
|---|---|---|
| 可观测信号 | 留点距拟合锚点的距离 | 留点预测投影到另两训练图后，与当地先验的深度冲突 |
| 参考误差 | 分组留点的SfM逆Z残差 | 完全相同的残差公式，不能进入评分 |
| 输入与计算 | 既有14个训练文件、CPU | 同样14文件、CPU；无需新模型或数据 |
| 不可观测情况 | 缺乏锚点观测 | 投影不在画幅、在相机后方、先验非正、拟合失败、少源图等全部保留 |
| 结论范围 | 不支持距离权重 | 只有真正执行后才能判断，当前没有D2指标 |

## 固定计算合同

同点跨图仍共享D1的确定性5折。对留点所在折k，**三个视图的拟合都排除该折全部point_id**；
按原始raw缓存和既有INTER_LINEAR规则各拟合一次无权float64仿射，共15项拟合记录。
沿用拟合点至少20、标准差至少1e-6、正斜率、拟合折逆Z中位数等原门槛。
单独复核原全量对齐参数只作来源检查；缓存全量target/valid/a/b/中位数及D1保存的折参数不定义D2评分或筛选。

在目标图i的留点位置p=(u,v,1)，先计算预测逆Z `q_i=a_i[k]*raw_i(p)+b_i[k]`。
若预测有限正值，用相机轴向Z而非射线长度反投影：

```text
P_i = inverse(K_i) * p / q_i
P_world = R_i * P_i + t_i                  # c2w_i = [R_i, t_i]
P_j = transpose(R_j) * (P_world - t_j)
uv_j = (K_j * P_j)[:2] / P_j.z
q_projected = 1 / P_j.z
q_j = a_j[k] * INTER_LINEAR(raw_j, uv_j) + b_j[k]
c_ij = 2 * abs(q_projected - q_j) / (q_projected + q_j)
```

源视图必须是另外两张训练图，固定逐一尝试；不按该点是否在源图有SfM轨迹挑源图。
源相机Z、采样预测必须有限正值，投影边界固定`2≤u<501, 2≤v<375`，坐标float32与原cv2采样约定一致。
不得把同一预测点来回投影的恒等关系当一致性证据；评分必须采样源视图自己的独立先验场。
留点的inverse_z、3D坐标或源图观测坐标不能进入评分。inverse_z仅事后计算原D1残差`abs(q_i-y_i)/m_fit`。
有限非正q_i仍保留该参考残差，但跨视图评分不可用；不能据此删掉该锚点记录。

两个源方向均可用时，主评分固定为二者算术均值；只有一个源时单列one_source_only，无源时no_source。
这两类不填零、不兜底进入主相关；仍保留原始参考误差、两条方向记录及原因。
预先固定失败判断顺序，见配置；固定记录610个目标行及1220个方向行，失败也占原行，不能删行造成选择性展示。
记录`sign(q_j-q_projected)`，正号只表示源先验更近，可能源于遮挡也可能是深度错误；**不用该符号剔除样本或宣称已判定遮挡**。

## 先检查反例，再看相关

几何单元检查必须包含已知平移/旋转、相机Z与射线长度区别，以及独立源场被破坏后评分会变化。
还要检验：只改折k中所有图的留点y，该折的拟合、投影、评分、可用性及m均不变，只有参考误差变化。

共同出错反例：在归一化相机坐标的局部正面平面上，真Z=10，但拟合后局部三图先验共同预测Z=20；
平行源相机横移±1，投影位置随之移±0.05，若源局部先验也为20，两个方向的冲突评分仍为0。
参考逆Z却由0.1变成0.05；若该折m=0.1，参考误差为0.5。这是几何推导示例，不是本轮已执行的合成检查。
例中的常量只描述局部区域，不是在整幅常量raw上绕过标准差门槛。
因此零冲突只能称为一致，不能标“可靠”；全局尺度/共同偏差、遮挡和重复纹理仍可能漏检。
目标预测同时出现在评分和参考误差中，二者也并非统计独立；正相关不等于独立深度真值验证。

## 冻结的分析与停止门槛

逐图和逐折报告两源评分与参考残差的Spearman平均秩相关；至少5个有限配对，常数或不足记null及原因。
逐图另外用评分自身的1/3与2/3分位数（NumPy method=linear）分低/高组：低组≤q1、高组≥q2；
q1≥q2或任一组少于5点则该对比不可用。保留全部中组行，不用参考误差选阈值；报告组数、误差及高减低均值。

必须同时报告各图/折的原始锚点分母、参考误差可用数、0/1/2源数、失败原因，以及主分析纳入/排除组的参考误差分布。
6个有序图对分别保留可用数、失败原因、冲突值与符号统计。可用性可能与误差相关，不能只展示留下的成功配对。
不计算p值、置信区间或混池像素显著性，不把610个观测或不同point_id当独立重复。

工程通过条件为公式、隔离和完整记录正确，不要求评分有效。研究方向只设置一次操作性筛查：

1. 每图至少50%的原始锚点具备两源评分及参考残差，且5折相关均有足够配对、秩不恒定。
2. 三图相关均严格为正，各图至少3/5折严格为正；三图高评分减低评分的平均残差均为正且对比可用。
3. 任一条件不满足，停止本范围评分路线并保留负/未知结果，不换阈值、聚合方式、折分或场景找收益。

50%与同向规则只是预先固定的投入停止条件，不是精度、显著性或实际收益标准。
即使全部满足，最多建议另行审阅同协议扩展到fern/flower的诊断；**不能放行权重、Phase 3或新训练**。
只有多个开发场景和后续公平对照提供足够依据，才可能评审Phase 3；鲁棒深度对照与独立测试仍是未完成事项。
