## 本次发现的参考循环风险

`export_train_anchors.py` 先由 SfM 三维点和相机计算 `xy`，只用原始特征
`measurement` 做 <=2px 筛选，最后保存的是重投影 `xy`，不是 measurement。
因此已有 anchors/*.npz 的坐标不能当作独立二维观测来执行新的留视图验证。
D1/D2 本来就是这些投影位置上的 SfM 代理诊断；本发现不改写它们的结果，
但进一步限制将它们外推为独立几何精度证据的做法。

另一个限制是原准备入口固定公开相机再进行训练图匹配和三角化。公开相机
可能来自全视角标定，不能称为独立三图恢复相机。原始轨迹也已经受 SfM
匹配/三角化选择影响；留视图检验只能是**固定相机和既有选中轨迹条件下**
的观测留出，不是对完整 SfM 管线的无偏验证。

- Li 等，2024，[DNGaussian](https://arxiv.org/abs/2403.06912)：
  深度约束与全局/局部归一化已有相关工作。我们接入深度先验不构成新颖性证据。
- Zhu 等，2024修订，[FSGS](https://arxiv.org/abs/2312.00451)：
  包含稀疏初始化处理与预训练深度/增强视角约束，是未来外部方法参考候选。
  当前未复现，论文结果不能作为本仓库对比结果，协议和资源须另评审。

以下敏感性公式是本项目的新开发候选，源自标准误差传播思路；未证明是
最佳评分或原创算法，不把公式可解释性当作实际相关、准确性或性能。

### 评分与留视图误差

每条被已有 SfM 接受的三图共同轨迹 t，分别留出图 i，源图只能是另外两张
j/k。三次留出都保留，共同轨迹之外的两图/单图轨迹记录数量与不可验证原因。
不按残差、视差角或先验值挑选轨迹，不额外套用旧锚点的2px/边界/同像素筛选。

1. 对源观测四维向量 z=(uj,vj,uk,vk)，使用冻结 K 和 c2w 逆矩阵构造
   归一化相机 DLT，float64 SVD 得 Xjk。矩阵行为 un*P3-P1、vn*P3-P2，
   不额外按行重加权；齐次化后投影到目标相机，定义 f(z)=pi_i(Xjk)。
2. 不使用目标观测 xi、单目深度或全量 SfM XYZ，逐源坐标以固定 h=1e-3 px
   中心差分，重新运行同一 DLT，得到 J=df/dz（2×4）。
3. 主评分固定 S=sqrt(trace(J*J^T))，按源像素独立单位方差假设解释为
   目标投影对1px源扰动的条件敏感性。它不是校准概率，也没有包含相机误差。
4. 参考阶段才允许使用留出观测 xi，参考量 r=||f(z)-xi||2（px）。r 只用于
   事后报告，不进入三角化、J、S、筛选、分组或阈值选择。
5. 简单对照固定 A=1/|sin(theta)|，theta 来自两条源观测反投影射线；
   theta 与 pi-theta 等价。不拟合角度模型、不按结果选择评分。
   在双方均可用的同一子集比较相关，同时展示各自排除集合。

归一化与相机约定使用轴向 Z，不把射线长度当 Z。源射线、DLT和每次扰动
均需有限，归一化场景下源/目标 Z>1e-12；齐次分母绝对值<=1e-12 或
SVD倒数第二奇异值<=1e-12倍最大奇异值时标记数值不可用，不加 epsilon 造解。
评分零值/并列保留；零正弦的 A 记null。无主评分不填零、不标为可靠。
只要原 f 与 r 有效，扰动失败时仍保存 r；原投影出目标画幅也照常计算 r，
因为不需要采样目标像素，不能因出界而选择性删除大误差。
相机后方、非有限值、缺轨迹等按独立状态保留，逐原因数量与分母全部报告。

### 分组与分析

不学习评分参数，因此这里的5折仅为按 point_id 的稳定性分组，不称为
OOF拟合。沿用现有 fold_for_id 的确定性规则，同一轨迹在所有图使用同折。
逐图、逐折报告 S 与 r 的 Spearman（并列取平均秩），不混池三图做推断。
固定 NumPy linear 的1/3、2/3分位数，低组<=q1、高组>=q2，报告原始 r
均值、高减低、样本数；q1>=q2 时对比不可用。A 使用同样规则，仅作对照。
完整报告三图共同轨迹、每图/折各状态、纳入/排除和三次留出的同点依赖。
所有 r 可用但 S 不可用的观测另报误差分布，不隐藏高敏感度或错误对应。
不计算把像素/相关轨迹视为独立重复的 p 值或置信区间。
