## 为什么改查普通鲁棒损失

原总指令要求简单鲁棒深度基线，用于检查收益是否其实来自普通残差处理。
[D2](leaves-crossview-prior-d2.md)不支持当前多视图评分，但这不排除更简单的深度约束工程方案。
现有[depth.py](../src/geosplat_r/depth.py)已经是归一化逆Z的L1，不能把从L2换鲁棒损失的论证直接套到这里。

[SciPy官方定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)给出Huber和Cauchy形状，并指出Cauchy可能增加优化困难。
本项目据公式推导：Huber在匹配L1尾部尺度后，大残差的梯度仍为常量；不能把它无条件称为比当前L1进一步抑制大误差。
因此本轮只预选一种Cauchy形状，同时公开标量归一化，不引入SciPy求解器、依赖升级或额外模型。
这是新的开发假设，提出时已经知道旧leaves结果；不是独立测试、预注册研究验证或新颖性贡献。

## 唯一候选公式与尺度

沿用当前有符号残差及同一有效像素集合：

```text
r = (1 / ED - aligned_inverse_Z) / median_train_anchor_inverse_Z
L_L1 = mean_valid(abs(r))
rho_c(r) = c * log(1 + (r / c)^2), c = 0.1
rho_prime(r) = 2 * (r / c) / (1 + (r / c)^2)
L_Cauchy = mean_valid(rho_c(r))
L_total = L_RGB + lambda * L_depth
```

c=0.1是一个预先声明的工程尺度，表示训练锚点逆Z中位数的10%，不是每像素10%的相对深度误差。
不根据新测试图、已知的逐区域误差拟合c，不做尺度或系数搜索；历史结果已经可见这一开发限制必须保留。
该归一化使残差梯度绝对值最高为1，与L1非零残差的梯度上限一致；这不是SciPy默认Cauchy系数，不能冒称默认设置。
大误差影响趋于零，但目标在|r|>c处非凸。**相同lambda和相同峰值梯度不等于平均约束强度相同。**

| abs(r) | Cauchy梯度绝对值（公式示意） | 完整L1 | 半强度L1 |
|---:|---:|---:|---:|
| 0.01 | 0.198020 | 1 | 0.5 |
| 0.05 | 0.800000 | 1 | 0.5 |
| 0.10 | 1.000000 | 1 | 0.5 |
| 0.20 | 0.800000 | 1 | 0.5 |
| 1.00 | 0.198020 | 1 | 0.5 |

上表是解析公式样例，不是实现测试或真实残差统计。Cauchy抑制很小和很大残差，相对强调中间尺度；不是只删离群点。
使用直接标量目标求导，不把诊断影响系数变成置信图，不按影响系数总和重新归一化，不增删像素。
对ED的梯度还含`-1/(m*ED^2)`及有效像素数分母，不能仅凭上表声称实际参数梯度等强。

把指标统一为越大越好（PSNR、SSIM、负LPIPS），每个指标m的预先固定筛查为：

```text
R_m = abs(A1_m - A2_m)
C_m - max(A1_m, A2_m, B_m) > R_m
```

三个指标均须满足；同时报告全部实际差值和原图结果。它只是单场景/单seed的后续投入筛查，不能声称显著、稳定收益或因果归因。
C不优于B时不能排除收益仅来自减弱约束；即使优于B，一个半强度标量仍不是穷尽的等强度对照。
若不通过，停止这个范围的候选或据首尾/工程异常标记未决，不自动补seed、换c/lambda或扩场景。
若通过，最多建议另行审阅相同协议的多种子扩展，不放行Phase 3、几何可靠性或最终测试。
